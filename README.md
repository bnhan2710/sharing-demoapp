# Sharing Demo App

This is a demo application developed for practicing **real-time communication**, including **chat** and **video call** functionalities using **WebSocket** and related web technologies.

The project is designed for learning purposes and to explore how real-time features are implemented in modern web apps.

## Features

- Real-time chat with multiple users using WebSocket
- Peer-to-peer video calling (e.g., WebRTC or similar)
- Simple and clean UI for testing communication features
- Built for experimentation and practice

## Technologies Used

- Frontend: HTML, CSS, JavaScript
- WebSocket (via native WebSocket API or libraries like Socket.IO)
- WebRTC (for video calling)
- Node.js + Express (backend WebSocket server)
